## Handoff model

New `ExecutionHandoff` records execution WIP movement between adjacent operations of the same ProductLine.

Lifecycle:
`TRANSFERRED → RECEIVED`

Each handoff preserves:
- dispatch;
- ProductLine;
- predecessor execution operation;
- successor execution operation;
- edge sequence number;
- explicit Decimal-safe quantity;
- transfer timestamp / actor;
- receive timestamp / actor;
- optional note.

Multiple partial handoffs are allowed on the same predecessor/successor edge.

## Transfer rules

A WIP transfer is valid only when:
- source and target belong to the same dispatch;
- source and target belong to the same ProductLine;
- target is the immediate routing successor;
- predecessor is `COMPLETED`;
- predecessor has explicit `produced_quantity`;
- target is not already COMPLETED;
- transfer timestamp does not precede predecessor actual finish;
- cumulative transferred quantity does not exceed predecessor produced quantity.

The system never creates quantity automatically.

## Receive rules

A handoff may be received only when:
- it is currently `TRANSFERRED`;
- the successor is not already COMPLETED;
- receipt timestamp is not before transfer timestamp.

Replay of the same receive evidence is idempotent.

## Successor eligibility

Before a non-first execution operation can START, G5.4 now verifies:
- an immediate predecessor exists;
- at least one WIP handoff from that predecessor has status `RECEIVED`;
- received quantity is greater than zero.

The first operation in a ProductLine route remains exempt because it has no execution predecessor.

This creates an explainable execution dependency without rewriting G2 routing or G4 schedule history.

## WIP trace projection

`ExecutionWIPTraceRead` derives:
- predecessor operation;
- successor operation;
- produced quantity;
- incoming transferred quantity;
- incoming received quantity;
- outgoing transferred quantity;
- outgoing received quantity;
- remaining quantity available to transfer.

This is an MES execution trace only.

It does not represent:
- warehouse stock;
- inventory balance;
- stock location;
- purchase receipts;
- material availability.

Those remain G6/G7 concerns.
