## Browser acceptance fixture
A non-production test plant with one published plan, one taquilla and at least two sequential operations in one ProductLine. Prepare a RELEASED dispatch via existing MES API. Use one user with mes.read+mes.edit and another with mes.read only.

Nominal run:
1. Operator opens MES / Planta, selects dispatch and first PENDING operation.
2. START yields RUNNING and persists timestamp; reload preserves state.
3. PAUSE with explicit reason yields PAUSED; RESUME returns RUNNING.
4. COMPLETE captures explicit quantity 9.5, timestamp and actor; no quantities inferred from plan.
5. Second operation is blocked until WIP is legitimately RECEIVED.
6. Handoff 4.0 + 5.5 and RECEIVE, then successor START succeeds.
7. Viewer cannot see mutating controls; server rejects mutation without permission.
8. Display published vs actual KPI; verify original G4 schedule remains unchanged.

Rework path:

2. Execute explicit repair loop; return to eligible target.
3. Verify WIP reconciliation and evidence without modifying G2 routing/G4 published operation.
