Date: 2026-11-03
Status: IMPLEMENTED — VALIDATION PENDING
Gate: G5 MES / Execution

## Functional scope
- Permission-aware MES / Planta navigation integrated into the authenticated AppShell.
- Dispatch selection with explicit RELEASED guard.
- Plan/Taquilla/ProductLine provenance preserved from actual dispatch snapshots.
- Operation list with PENDING/RUNNING/PAUSED/COMPLETED state.
- Operator capture: START, PAUSE with reason, RESUME, COMPLETE with explicit Decimal quantity.
- Real-resource optional UUID input and deviation-reason field (server validates).
- Dispatch KPIs from G5.6 read-only feedback.
- Server remains sole authority for predecessor/WIP and setup eligibility.
- Honest HTTP error and idempotent-replay messages.
- Read-only access for users without mes.edit; no mock data, no direct G4 mutations.
- Touch-oriented responsive CSS.

## Surfaces
`frontend/src/shell/MESPanel.tsx`, `AppShell.tsx`, `frontend/src/lib/permissions.ts`, `styles.css`.
Frontend permission test: `frontend/src/shell/MESPanel.test.ts`.

## Limits
- This slice does not create a dispatch or publish an APS run. Operations require an existing RELEASED MES dispatch.
- The quick capture is for nominal operation START/COMPLETE/PAUSE/RESUME; advanced setup, WIP handoff and rework controls retain existing authenticated APIs for specialist workflows.
- Plan, Taquilla and product association in the operation list are currently shown with abbreviated canonical IDs; descriptive names are an improvement for the subsequent usability refinement.
- Resource selection is ID-based pending a resource picker. No fictional work-center matching.
- No warehouse, purchasing, maintenance or workforce authority is introduced.
- User-facing UI remains in development until live browser acceptance and G5.8 gate hardening.
