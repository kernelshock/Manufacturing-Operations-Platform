**Scope:** G6.8 acceptance with isolated test resources; no production deployment, no FAIC inventory data, no automated purchase decisions. `feat/G6-materials` remains OPEN / DRAFT / UNMERGED.

## Script

`infrastructure/scripts/g68-local-gate.sh`

Run on `zrtserver` **after** synchronizing `feat/G6-materials` and ensuring the local working tree is clean:

```bash
cd ~/dev/Manufacturing-Operations-Platform
bash infrastructure/scripts/local-sync-checkpoint.sh sync feat/G6-materials
bash infrastructure/scripts/g68-local-gate.sh
```

Preflight requires a functional Docker daemon, Chrome (`google-chrome`), Node/npm, and Python 3.14 with locked MOP dev requirements. If Python 3.14 dependencies are not already in a dedicated virtual environment, prepare them before invoking the gate:

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -c requirements-dev.lock.txt -e '.[dev]'
MOP_G68_PYTHON=.venv/bin/python bash infrastructure/scripts/g68-local-gate.sh
```

Do not blindly reinstall dependencies into the global Python environment. `runtime-data/` is ignored by Git. G6.8 test logs and ephemeral runtime configuration are local, not part of the public repository.

## Executed by runner (when invoked on zrtserver)

- Verify exact local/remote branch SHA, and refuse dirty or divergent worktrees.
- Start a unique disposable PostgreSQL 18 container with randomly allocated localhost port; migrate / schema-check / downgrade / replay / schema-check.
- Run `pytest tests/g0 ... tests/g6 -q -ra`, plus tracked-secret and supply-chain pin scans.
- Run `npm ci`, `npm audit --audit-level=high`, `npm run typecheck`, `npm test`, `npm run build`.
- Run the existing full `runtime-smoke.sh` under a uniquely named Compose project, with ephemeral credentials, separate test volume and real Chrome against React/FastAPI/PostgreSQL.
- Save per-step `.log`, `summary.txt` and `commit.txt` under `runtime-data/g68/<session>/` and stop at first failed stage. Does not reset code, merge, post production stock, or ship artifacts.

## Guardrails / interpretation

- Do not run if TCP 18080 is already occupied or `MOP_COMPOSE_PROJECT` is set. The gate is configured to fail closed.
- A green `summary.txt` only establishes the **configured** checks. Audit `pytest` skips, accepted regression breadth, identity/permissions, and the G6.7 data-bearing browser scenario before declaring the gate released.
- Browser Materials coverage currently checks navigation/rendering; complete data-bearing browser acceptance remains a documented separate blocker.
- The GitHub connector currently cannot attest push-triggered workflow results for the exact SHA from its commit-run listing; CI success must be confirmed from GitHub Actions separately.
- Local machine execution is user-initiated; a newly created script or its commit is never evidence that it ran on zrtserver.
- Preserve the user-provided terminal `summary.txt`, failing stage log and `commit.txt` as G6.8 evidence. Do **not** share `.env.runtime-ci` or secrets.
