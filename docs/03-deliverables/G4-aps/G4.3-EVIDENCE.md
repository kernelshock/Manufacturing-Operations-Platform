## Objective

- weekly windows, overnight windows, CLOSED exceptions and AVAILABLE_OVERRIDE exceptions;

- scenario horizon clipping;
- structural run transition `EXPANDED → CAPACITY_PROJECTED`;
- idempotent replay;
- API for projection, capacity candidates and availability intervals;
- `aps.edit` protection for projection and `aps.read` for reads;
- audit event `aps.run.capacity.project`.

## FAIC shift invariant

Integration validation includes the FAIC-style Monday shift:
- 07:00–12:00 available;
- 12:00–12:30 unavailable lunch gap;
- 12:30–16:00 available.

The projection produces two distinct availability intervals and never converts the lunch gap into capacity.

- schedule publication;
- Gantt positioning;
- MES actuals;
- maintenance/workforce/material constraints not yet owned by released gates.
