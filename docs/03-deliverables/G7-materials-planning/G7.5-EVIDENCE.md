## 2. Quantitative model and policy

**Coverage horizon:** explicitly selected positive number of business days, defaulting to `PlanningPolicy.horizon_business_days` (15). This is a **target-stock horizon**, not a supplier's contractual delivery time and not G4's time-phased plan.

**Target stock** = selected verified daily material demand × target coverage business days + G7.4 safety stock.

**Quality-unallocated** = Quality-usable physical stock − G6 active holds (the hold is deducted exactly once by the upstream policy; never subtract it again).

**Confirmed incoming** = explicit plant/article/UoM quantity with independently verified reference. An unassigned, partial Prolowin PO or receipt transcript is **not confirmed inbound**.

**Raw CALCULATED C.R.** = max(0, target stock − Quality-unallocated − confirmed incoming).

**CALCULATED rounding:** If raw C.R. is zero, remain zero (no forced MOQ). Otherwise take max(raw C.R., verified supplier MOQ) and round **up** to a verified pack multiple. The result is PROVISIONAL if any packaging adjustment was required; it must be reviewed by a person.

**FIXED C.R.:** Uses the strictly positive user-governed fixed quantity from the G7.1 policy. It is never silently altered. If below verified MOQ or not an exact multiple, the scenario is BLOCKED. When target deficit is zero but fixed C.R. is positive, return an explicit caution for human review.

**Source confidence:** For a numeric C.R. require non-blocked G7.4 P.P. scenario, known Quality-usable stock, selected traceable daily demand, supplier terms with VERIFIED status, independently confirmed source-specific incoming (zero allowed only when verified), and aligned plant/article/UoM. An incomplete source blocks a C.R.; it is never silently treated as zero. Existing G7.4 PROVISIONAL warnings remain visible.

**Comparison:** `compare_scenarios` keeps multiple suppliers' proposed quantities under distinct scenario keys in a stable order and rejects plant/article/UoM crossover or duplicate keys. It **does not rank, select or switch supplier automatically**, and has no price optimization.

## 4. Important boundaries and unresolved dependencies

1. **G7.5 is a pure policy engine, not a public endpoint, planner UI or production purchasing service.** Consumer UI and executive reporting belong to G7.7. No new migration, persistence or automatic PO action was introduced.
2. The source-verified supplier MOQ/pack values and supplier-confirmed incoming are explicit scenario input contracts. **There is not yet an automated trusted FAIC supplier-terms feed**. This module cannot certify manually typed terms by itself; verification must come from a separately authorized source before operational use.
3. The G7.2 time-phased future inventory position, Quality lot release state, validated plant-specific inbound mapping and verified FAIC production demand remain OPEN. Until available, C.R. values are **what-if demonstrations**, not approved procurement execution quantities.
4. G7.3 manual/screenshot Prolowin sample coverage remains UNKNOWN for global supplier history. An ERP promise does not add inventory and is never assumed to be confirmed inbound for any plant.
5. G7.4 demand-rate sources are still explicit scenarios; normalization of all BOM, MES and product/seat history is not fully automated. Per-seat/product representations are not added together.
6. The C.R. calculation **does not imply supplier preference, price competitiveness, quality approval, lead time certainty or award of purchase**. These need governed exceptions/authorization in G7.6.
7. No live FAIC data, physical inventory, production deployment, supplier order or `main` merge was performed. G7 remains exclusively on `feat/G7-materials-planning`.
